In 4 Schritten – dauert ca. 3 Minuten
1

Kostenlos – du brauchst nur ein Google-Konto, das du wahrscheinlich schon hast.

2
Mit Google einloggen
Einfach dein bestehendes Google-Konto verwenden – keine neue Registrierung nötig.
3
API-Key erstellen
Oben links auf „Get API key" tippen → „Create API key" → Key kopieren.
Direkt zum API-Key ↗
4
Key hier einfügen
Unten auf „Weiter" tippen und den Key einfügen (beginnt mit AIza).
🔒 Dein Key wird nur lokal im Browser gespeichert – nie auf unseren Servern.
